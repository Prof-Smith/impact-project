# Impact Project

## Knowledge Applied. Purpose Realized.

A polished informational prototype for a proposed four-year undergraduate learning progression.

## Included

- Four-year curriculum map
- Annual student milestones
- Seven project pathways
- Common project criteria
- Student guidance
- Faculty and program guidance
- Responsive, accessible static design

## Prototype boundaries

This version:

- Does not accept student submissions
- Does not collect student information
- Does not upload or store files
- Does not provide AI feedback
- Does not issue academic approvals
- Does not replace official program or university processes

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload all files and folders from this package to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings > Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Select **Save**.

## Editing

Edit the `.html` files for content and `assets/styles.css` for styles. No build process or dependencies are required.

## Updating an existing repository

Delete the previous site files from the publishing source, then upload the contents of this ZIP directly to the repository root. Confirm that `index.html` and `assets/impact-brand-v2.css` appear at the root structure shown in this package. Commit the replacement and verify the latest Pages deployment. The versioned stylesheet reference prevents the previous blue stylesheet from being reused from cache.
